How the container becomes usable

Your identity is forwarded securely, hardened by default

An empty container is useless. The provisioner forwards exactly what code needs to run — credentials, tokens, and preferences — while clamping the container down so nothing leaks or escalates.

Git + GitHub Flattens host .gitconfig (resolving [include] chains); injects GH_TOKEN + GITHUB_TOKEN as real container env vars — verified in the report.
API keys Auto-passthrough for OPENAI_*, ANTHROPIC_*, AZURE_* and dozens more — 30+ env vars forwarded with zero manual setup.
Dotfiles + SSH Clone a dotfiles repo and auto-run its install script; opt-in SSH bind mount with corrected 700/600/644 permissions.
Security no-new-privileges, 4 GB memory cap, PID limits, bridge network only — never privileged.
