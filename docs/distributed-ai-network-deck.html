The Tension

It was built in 15-second pauses —
while playing GTFO with my kids.

The Pi was sitting next to me, idle. I never wrote a deployment plan. I described goals out loud between door-hacks and got back to the game.

No IDE. No SSH marathon.
Just spoken goals, mid-raid.

The Breakthrough

It didn’t deploy to the next box itself…

It told the first box it had set up
to go deploy to the second box.

Autonomous agent-to-agent delegation — I never asked for it. I described a goal, and the coordination pattern emerged on its own.

How It Started

Amplifier on a barely-configured Pi 5

I dropped Amplifier on a barely-set-up Raspberry Pi 5 with an unknown USB conference speaker/microphone puck — then had it configure the rest of the Pi for me, figuring out the hardware through conversation.

Me “Can you hear me now?”
AI “Yeah, but it was on the main speaker.”
Me “How about now?”
AI “Yep, that’s the right one.”

Then it did the rest.

How It Works · Voice

A voice interface, built entirely by talking to it

The result was an Alexa-like flow — the on-ramp for every spoken goal that followed.

  • Wake word detection
  • Talk naturally
  • It processes and does the work
  • Responds via speaker
  • Continue… or it times out for later
The Flow
"Hey Amplifier" ↓ [listening...] ↓ "Do the thing" ↓ [processing...] ↓ "Done. Here’s what I did." ↓ [waiting for follow-up or timeout]
How It Works · Spoken Infrastructure

“Build the service so my boxes can talk” — then back to the game

During a ~15-second pause in the action, I gave it a task and returned to the raid. It kept working across the next pauses.

Pause 1
“Go build the service”
Pause 2
“Kick the tires” — test it out
Pause 3
It asked about other devices; I authorized it on my Tailscale network in seconds
Pause 4
It deployed to my first box — a DGX Spark
How It Works · Judgment

It profiled the hardware and reasoned about architecture

Deployed to the DGX Spark, the agent recognized what it was working with — and volunteered a design idea I hadn’t asked for:

“This has a killer GPU and excessive memory.”

“We should offload the voice processing to this device to use local models.”

— Bonus observation from the agent

It wasn’t just following instructions. It was thinking about architecture.

The Turn · Real Work

Then it split real dev work across the network

I came back later and had the coordinator divide a real build between the two workers:

The Insight

I didn’t tell the agent to delegate to another agent. I described a goal.

It figured out the multi-agent coordination pattern on its own — from gaming pauses to a self-deploying agent network. That’s the casual future of AI infrastructure.
