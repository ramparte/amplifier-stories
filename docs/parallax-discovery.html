Not a plausible narrative. True understanding—with proof you can ship. Here is how it gets there.

One agent's answer is confident—and incomplete. Every time.

Incomplete by default

Send one agent at a complex system and it returns findings that seem reasonable but are partial. Send a second and it finds different things. No single pass is the full picture.

Docs ≠ reality

Documentation describes the intended design; code reveals the actual one. They diverge, and each agent silently inherits the last one's blind spots.

Confident & wrong

An LLM session produces a plausible, confident narrative that can be confidently wrong. Without adversarial verification you can't tell insight from illusion.

So we stopped trusting any single vantage point—and borrowed a trick from astronomy.

Parallax fixes a star's true position by looking from two places

In astronomy, the apparent shift of a star between two vantage points reveals its real distance. Point independent agents at the same system and the same logic holds:

Agreements confirm

When isolated agents reach the same finding from different angles, confidence is high—corroboration through isolation.

Disagreements reveal

When they find different things, that's not noise to average away—it's a priority to investigate. Discrepancy is signal.

We learned this the hard way porting the dev-machine bundle (an autonomous coder that built a 166K-line word processor). The port's review loop couldn't converge—and single-agent investigation couldn't tell us why. So we built Parallax.

Three fresh-context agents per topic—so disagreement means something

Each topic gets 3 agents with context_depth="none". Genuinely isolated—so overlap is real corroboration, not shared bias.

Code Tracer HOW

Traces actual execution paths with file:line citations and LSP navigation.

Every team had at least one agent surface something the others missed. Now watch what those disagreements let the method do.

Each wave is more adversarial than the last—and a human steers between them

That self-correction is structural: findings funnel through escalating rigor, gated by human approval.

Wave 1: Discovery Broad, triplicate. 3 independent agents per topic, fresh context, wide net. Output: reconciliation with the discrepancies made explicit.
▲ Approval Gate — human reviews & steers Wave 2
Wave 2: Verification Focused, expert. One expert per discrepancy, code-level deep dives, file:line evidence required.
▲ Approval Gate — human reviews & steers Wave 3
Wave 3: Adversarial Execution-based. Challenge each claim by running code. Verdicts: CONFIRMED / REFUTED / CORRECTED.
▲ Approval Gate — human reviews
Wave 4: Synthesis Final deliverables. Unified understanding, architecture diagram, evidence catalog, actionable plan.

Execution proves impact; code reading only names the mechanism

Why the waves escalate: not all evidence is equal, and the method ranks it strictly.

1 Execution evidence Ran code, observed behavior, captured output. Gold standard. The antagonist agent operates here.
2 Code tracing File:line citations, LSP navigation, followed logic. Code Tracer & Integration Mapper operate here.
3 Documentation Read docs, README, comments. Medium reliability. Behavior Observer spans here.
4 Assumption Inferred from patterns. Must be flagged explicitly. Every agent lands here sometimes.

That ranking is what turns an investigation into a fix—as the dev-machine port showed.

The Convergence Layering Principle

“The termination condition of an iterative loop must be more deterministic than the loop body.”

Dev-machine gated one feature's diff against one feature's spec with deterministic exit codes. The port reviewed the whole codebase with probabilistic termination. Six boundary failures confirmed the diagnosis.

The result shipped as PR #45. Briefs now converge autonomously in 7–27 minutes—was: a human, every time.
