The Problem

Every agent was burning
frontier tokens

  • One model fit all: Every delegated agent inherited the parent's model — usually Opus or the most expensive option available
  • Wasteful spend: Git commit formatters, file readers, and shell commands all ran on frontier-class models
  • Rate-limit collisions: Parallel instances competed for the same model's quota, causing cascading throttling
  • Unnecessary latency: Simple tasks waited on frontier response times when a fast budget model would do

The fix isn't a knob to tune by hand — it's the right model for every agent, automatically.

Budget agents get downgraded and planning agents get upgraded. So how does an agent know its tier?

How Tiers Are Decided

Each agent declares its own tier in its frontmatter

There's no central routing table to maintain. Every agent's .md file carries its own provider_preferences — the ordered provider + model pairs that define its tier. Routing is a property of the agent, and it inherits cleanly.

Declared at the agent
16 agent .md files now set provider_preferences in frontmatter. The tool-delegate agent reads those defaults at delegation time — no caller changes required.
Override & inherit
Callers can always pass explicit provider_preferences to override the default, and derived bundles like amplifier-dev inherit automatically through a shared loader.

A tier names a pattern, not a fixed model — so what turns claude-haiku-* into a real model?

How Routing Stays Robust

Globs pick the newest model — with a four-provider safety net

Preferences are written as globs, not pinned versions, so agents ride model upgrades for free. Each pattern resolves to the newest matching model at runtime, and every tier carries a full provider fallback chain behind it.

🎯 Glob resolution

  • claude-haiku-* — matches any Haiku variant
  • gpt-5.[0-9] — character class catches only base flagships, skipping gpt-5.0-mini
  • Models sorted descending — newest version wins
  • Patterns auto-resolve at delegation time

🔗 Four-provider fallback

  • Every tier chains Anthropic → OpenAI → Google → GitHub Copilot
  • If one provider is down, the next takes over seamlessly
  • Caller override always takes precedence
  • No config changes needed for existing users

That's the engine today. It already reaches further than the defaults.
