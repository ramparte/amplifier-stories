The tool

One tool gave the agent eyes

terminal-tester adds a single tool — terminal_inspector — with nine operations that let an agent launch a TUI, look at it, act on it, and wait on what it sees. No wiring, no config: it auto-detects how to capture the screen.

# 1 tool, 9 operations terminal_inspector spawn | screenshot | send_keys | send_text find_text | wait_for_text | resize | close | list

Repo: microsoft/amplifier-bundle-terminal-tester

How it sees

It can screenshot any terminal app

The single claim: two capture modes cover everything, and the agent never has to choose — if the command carries --screen-dump-path it dumps, otherwise it falls back to PTY.

📸
Screen-dump mode
Reads Ratatui's own render buffer — pixel-perfect, frame-numbered, zero ANSI parsing.
Ratatui crossterm
🖥️
PTY mode
Universal VT100 emulation via pyte — works with Textual, Bubble Tea, urwid, or any plain CLI tool.

The specialists

Three agents turn seeing into testing

The one claim here: raw screenshots aren't QA on their own — three specialist agents give the eyes a job.

🤖
terminal-operator
Launches apps, drives interaction, verifies results — a 6-step workflow with a 3-attempt failure budget before escalating.
📐
terminal-visual-tester
Responsive layout testing across 6 breakpoints (60→200 columns), running visual quality checklists on every screen state.
🔬
terminal-debugger
Frame-by-frame analysis and keystroke-response verification, with root-cause reports carrying file:line citations.
The turn

It doesn't just spot a bug —
it names the exact line of Rust

Seeing is only half of it. The debugger agent pairs live terminal inspection with Rust source analysis:

▸ Traced a markdown rendering bug from its visual symptom to two specific lines of Rust

▸ Used frame-counter analysis to tell whether keys were received, handled, or just not re-rendering

▸ Produced structured root-cause reports with file:line citations, fixes, and confidence ratings
// Debugger output structure { "symptom": "Markdown not rendering", "root_cause": { "file": "src/ui/chat.rs", "lines": [142, 147], "issue": "Raw text passed instead of parsed spans" }, "confidence": 0.92, "fix": "Replace raw & with markdown::parse()" }
