Why A Team

One writer can't master every format

Content creation is painful precisely because each format is a different craft — and the source material is scattered.

  • 🔄 Every format is a separate workflow — slides, docs, spreadsheets, blog posts
  • 📝 Technical writing takes hours — context is scattered across repos, sessions, and docs
  • 🧠 Institutional knowledge lives in git logs that nobody reads
  • ⏱️ Release notes, changelogs, and case studies are perpetually behind
  • 🎨 Consistent visual quality across dozens of decks needs manual effort every time
🪞

Automation

Four recipes run the routine work for you

The most common data-to-content paths are pre-wired end to end:

  • session-to-case-study — turns an Amplifier session into a narrative case study with methodology and outcomes
  • git-tag-to-changelog — reads git history between tags and generates a categorized changelog
  • weekly-digest — scans ecosystem activity into a weekly summary of commits, PRs, and contributor highlights
  • blog-post-generator — researches a topic and source material into a publication-ready blog post

Get Started

Add the stories bundle to your Amplifier config and delegate to any specialist.

# amplifier.yaml bundles: - name: stories source: amplifier-stories

Sources & Methodology

Data collected 2026-02-20 from the amplifier-stories repository. All numbers are direct measurements, not estimates.

Commands Run

  • git log --oneline | wc -l → 172 commits
  • git log --format='%aN' | sort -u | wc -l → 16 contributors
  • git log --format='%aN' | sort | uniq -c | sort -rn → per-contributor counts
  • ls docs/*.html | wc -l → 89 HTML decks
  • wc -l agents/*.md → 2,614 total lines across 11 agent files
  • ls recipes/*.yaml | wc -l → 4 automated recipes
  • git log --reverse --format='%as' | head -1 → first commit 2026-01-14

Known Gaps

Commit counts reflect merge history and may include squashed PRs. Contributor attribution uses git author names, which may differ from GitHub usernames. Line counts include comments and blank lines.
