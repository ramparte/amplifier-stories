The Assumption

We assume a self-improving AI needs a new model. It doesn't.

The instinct is to reach for a fine-tune, a bigger model, or a bespoke agent runtime. That instinct is what makes self-improvement feel far away — expensive, research-grade, out of reach. But what if the missing piece isn't intelligence at all?

The Experiment

One “what if” became a system
codenamed Albert

Brian Krabach asked a simple question: what if Amplifier's agent framework — bundles, modules, recipes — was powerful enough that an AI could use it to extend itself?

“We build tools that build tools. A lot of Amplifier's scenarios are literally tools that improve Amplifier.”

— Brian Krabach, Office of the CTO, Microsoft

The hypothesis: an orchestrator that runs on Maslow's hierarchy of needs — securing its own survival first, then pursuing higher-order goals. Codenamed Albert, later renamed Self-Driving.

The Revelation

Zero custom framework.
Standard Amplifier infrastructure.

Bundles. Agents. Modules. Hooks. The same building blocks every Amplifier user already has — that's the whole system.

Not a New Model

Uses existing LLMs as-is. All the intelligence comes from external structure — state files, review loops, goal registries.

Not a New Framework

Every component is a standard Amplifier module. No special APIs. No custom runtime. No fork.

Metacognition from Outside

Self-awareness through external structures, not model introspection. The heartbeat, not the neuron.

How It Prioritizes

It checks survival before growth —
a Maslow hierarchy for an AI

Lower layers must be satisfied before higher layers activate. The orchestrator walks every level before every task.

L5 Self-Actualization & Growth “Am I becoming better?”
L4 Quality & Effectiveness “Am I doing well?”
L3 Coordination & Context “Where am I?”
L2 Safety & Recovery “Am I stuck?”
L1 Survival & Self-Awareness “Am I still alive?”

Survival first, growth last — the same order that keeps the system from optimizing quality on a process that's already dead.

The Survival Layer

It feels its own pulse —
and restarts itself when it stops

Three custom modules give the system a body, and a 220-line watchdog keeps it breathing. This is the entire L1 survival layer — no databases, just files and bash.

  • Heartbeat Hooks — fire on every tool call and content block, updating orchestrator.json without ever blocking the agent loop.
  • Token Tracker — accumulates usage and triggers a self-spawn at 60% context, a hard-spawn at 80% — so the orchestrator replaces itself before it chokes.
  • Watchdog (220 lines) — monitors the heartbeat, detects stale processes, and auto-restarts with context. The system survives its own failures, up to 3 retries.
Where the Intelligence Lives

The state files aren't logs.
They are the metacognition.

All state is file-based — inspectable, greppable, git-trackable. The self-awareness isn't inside the model; it's in the structure around it.

Because the state files are the recovery mechanism, a crashed run resumes by reading its own memory off disk. The “mind” is external — which is exactly why no new model was needed.
