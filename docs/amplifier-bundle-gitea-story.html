The whole point

Mirror, work, promote —
then throw it away

On-demand, ephemeral Gitea Docker instances. Mirror real repos, work freely in isolation, promote results back to GitHub when ready — then destroy.

1

Create

Spin up a Gitea Docker container with one command. SQLite-backed, offline-mode, hardcoded admin — optimized for ephemeral use.

2

Mirror

Snapshot a GitHub repo into Gitea — git content, issues, PRs, and labels. One-time copy, not continuous sync.

3

Work

Freely create branches, commits, issues, and PRs against the Gitea instance. Zero impact on GitHub.

4

Promote or Destroy

Push a branch back to GitHub as a PR via HTTP (no git binary needed), then tear down the container.

How promote-back works

Promotion is pure HTTP — no git binary on the host

The promote-to-github command never shells out to git. It fetches trees from Gitea and GitHub over their APIs, diffs them, then rebuilds the change through GitHub's Git Data API.

  • Fetch the Gitea tree and the GitHub tree via API, then diff
  • Create blobs → trees → a commit → a ref, all over HTTP
  • Open the PR on GitHub — entirely from API calls

No git binary required anywhere on the host — the promotion bridge is just HTTP, which is what makes it safe to run inside any container or agent.

How it stays disposable

Docker labels are the only source of truth

There are no local metadata files to drift or clean up. State is discovered by querying Docker labels directly — so "throw it away" really means gone.

Labels, not files

All instance state lives on the container's Docker labels. Destroy the container and every trace is gone — nothing left behind to reconcile.

Opinionated ephemeral defaults

SQLite, offline mode, hardcoded admin. Optimized for disposable use, not configurable complexity. Consumer still controls networking via --network, --add-host, --hostname.

How the agent knew what to do

One tool, two faces: a CLI and an Amplifier bundle

It's a standalone CLI (every command returns JSON to stdout) and an Amplifier bundle with skills, behaviors, and context — so agents drive it natively, the way the demo did.
