Quality in One Call

rust_check runs four checks,
returns structured results.

One call. Formatting, linting, type-checking, and stub detection — each result carries file, line, code, message, and severity the agent can act on.

What it runs

🎨 cargo fmt Formatting
📎 clippy Linting
⚙️ cargo check Type / Compile
🔎 Stub detection Completeness

Stub detection catches half-done code

todo!()          // caught
unimplemented!() // caught
unreachable!()   // caught
// TODO           // caught
// FIXME          // caught

// Smart exemptions:
unreachable!() in match arms → OK
todo!() in test files     → OK

Warm, Not Cold

A persistent rust-analyzer
makes every call after the first instant.

The server stays alive for 5 minutes between calls. The first call starts the proxy; every call after that skips startup and indexing entirely.

First Call

~3s

Server startup + workspace indexing

Subsequent Calls

instant

Server already warm, cached analysis

// Server lifecycle
Call 1  →  start_proxy()  →  rust-analyzer boots  →  response
Call 2  →  proxy alive    →  instant              →  response
Call 3  →  proxy alive    →  instant              →  response
  ...
5min   →  idle timeout   →  server shutdown      →  clean exit

Beyond standard LSP

expandMacro — see what derive(Debug) and vec![] expand to.

relatedTests — find every test that exercises a function, without running them.

⚠ Note: extensions need a standalone rust-analyzer build; the rustup component build has limited support (a documented upstream limitation).
