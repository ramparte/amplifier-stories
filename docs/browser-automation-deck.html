The Gap

Fetch returns
empty divs

Modern web apps hand a plain fetch almost nothing to work with:

  • No JS execution - React, Vue, and Angular SPAs render as empty divs.
  • No authentication - login forms go unfilled; gated content stays gated.
  • No visual verification - nothing can "see" the page, so layout bugs slip through.
  • No interaction - no clicking, typing, or navigating; static reads only.
Modern web apps need a real browser.
The Point

Give agents
eyes and hands

Hand an agent a real browser and it stops parsing HTML and starts behaving like a person.

The Philosophy
"Be a user, not a script." Explore naturally, screenshot only what matters, and ask a human when stuck.

Control it in natural language - just describe the outcome - and stable ref-based targeting (@e1, @e2) keeps actions reliable as the page changes. That single shift is what powers everything that follows.

Dogfooding

Amplifier validated its own SDK by using it

The meta story: Amplifier building and testing itself.

Context
An example web app with a TypeScript frontend and a Python server - used to self-validate the SDK during development.
What the browser bundle enabled:
  • Launch the example app in a real browser
  • Interact with SDK features as a real user would
  • Validate the TypeScript bindings work correctly
  • Exercise the Python server integration end-to-end
  • Report issues found during automated exploration
Key Insight
"Amplifier used browser automation to develop and validate its own SDK."
