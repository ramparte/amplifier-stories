The Backstory

The Storyteller was the new specialist
everyone was trying to prove

Canvas-specialists is a bundle of 6 AI specialist agents for structured knowledge work — a Researcher, a Formatter, a Data Analyzer, a Competitive Analyst, a Writer, and the newest addition: the Storyteller.

The Storyteller selects a framework, assigns narrative roles to findings, and writes prose that makes people care — with a full editorial record of what it included and why. Story 1 covered the design. This is what happened when we tried to prove it works.

The Realization

Run 1 had already named the problem—
we kept testing anyway

We spent more time evaluating the Storyteller than fixing the problem the first test already identified.

Run 1 told us the answer: the Storyteller adds narrative lift but bleeds precision when its output feeds the Writer. Runs 2 and 3 generated noise because n=6 is underpowered — three rounds to characterize a problem one round already named.

Act 4 — The Turning Point

There was only one way to answer: stop projecting, run the chains, and look at the output.

The Real Problem

not the new specialist

An honest audit of all 6 specialists and 8 chains found it: the Researcher’s output was canonical only ~1 in 3 topics, the Formatter that fixes it was merely “optional but recommended,” and the Writer dropped structural blocks on malformed input.

Everyone watched the new specialist.
The old ones were the ones breaking.

The Honest Answer

The new scorecard was honest:
the ratings were only theoretical

The ratings are my projection based on what the instruction changes should do — not confirmed through live testing.

LLM instruction adherence is not guaranteed. A rule that says “always insert the Formatter” might be followed — or not. A Writer told to produce structural blocks on non-canonical input was told that before, too. And it failed.

The Evidence

Live tests split: one chain genuinely fixed,
one still broken

Researcher → Writer ✓

Every checkpoint hit. Formatter auto-inserted. 9 findings traced to 9 S-numbered claims. 347 words, all structural blocks present.

Genuinely fixed.

Comp Analysis → Writer ✗

Good substance, wrong format. Markdown tables and prose instead of the pipe-delimited matrix. Zero source URLs. The instruction changes didn’t take.

Still broken.

An instruction fix that looks right
is not the same as one that works.

Act 6 — The Stitch Fix

The precision bleed was
one missing input type

The Writer recognized researcher-output, analyst-output, and raw-notes. It had no idea what to do with story-output. So when Storyteller prose arrived, the Writer parsed narrative as factual claims. Not a deep design flaw — a missing case in a switch statement.

Writer (story-output)

The rule: source claims from the Storyteller’s INCLUDED FINDINGS block, not the prose. “If you can’t trace it to an included finding, cut it — even if it sounds good.”

The Storyteller’s narrative lift is
statistically real. p = 0.011.

The stitch problem that took three blind rounds
to characterize was solved with one new input type—
not because of more testing.

Because someone asked
“how do you know?”
and got an honest answer.

Sources & Methodology

Data as of: March 6, 2026

Type: Validation case study from Amplifier session

Project: canvas-specialists (specialist agents bundle)

Blind testing protocol:

  • 3 blind runs, 2 independent judges per run, 3 variants per run = 18 scorecards
  • Frozen evidence pack: 8 documents (Doc A–H), line-numbered, strict citation rules
  • Randomized X/Y/Z labels — judges never saw variant names
  • 5 rubric criteria, each scored 1–5
  • Same scenario across all runs: on-device SLM integration strategy memo

Statistical methods:

  • Kruskal-Wallis omnibus test (p=0.352 overall, p=0.011 Narrative Memorability)
  • Cohen’s d > 2.0 for Storyteller vs. Writer-only on Narrative criterion
  • Power analysis: ~26 scorecards per variant needed for reliable overall detection
  • Coefficient of variation used for consistency comparison

Artifacts:

  • PR #16 merged to main (commit 9bbb3ba) — chain reliability + story-output fix
  • Blind test artifacts on feat/blind-abc-test branch (commit 4fe5214)
  • Chain smoke tests executed live during session
  • Stitch test: 10 narrative traps, 15 S-numbered claims, 24 traced statements

Gaps & open items:

  • Competitive Analysis format compliance — confirmed insufficient, not yet re-addressed
  • Single-domain test scenario — all runs used the same topic
  • Chain smoke tests not independently re-verified
