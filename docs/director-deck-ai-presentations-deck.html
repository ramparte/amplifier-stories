How It Works · Inputs

Feed it anything: a prompt, a PowerPoint, or a web deck.

Three input modes meet your content where it already lives.

📝

Text Prompt

Describe it in plain language. The Ghost Deck Writer crafts 8–12 slides with assertion titles, a storytelling framework, and a full visual identity.

📊

Existing PPTX

Drop in a PowerPoint. Content, speaker notes, theme colors, and fonts are extracted verbatim; slide count is preserved exactly.

🌐

HTML Presentation

Pass a URL or file. Playwright screenshots each slide at 1536×864; DOM text and CSS design tokens are extracted automatically.

How It Works · The Pipeline

Five agents enrich one contract — and you approve every gate.

1

Ghost Deck Writer

Creates slide_deck.json and DESIGN.md — content, storytelling framework, visual identity, and Veo transition prompts.

2

Slide Architect → Gate 1: review wireframe

Builds wireframe HTML and PPTX previews. You review layout and flow before any image is generated.

3

Visual Director → Gate 2: review images

GPT Image 2 renders each slide as a full 2560×1440 image — atmosphere, type, layout in one shot — before transitions.

4

Transition Director → Gate 3: review transitions

Veo 3.1 generates cinematic clips between each pair of slides, retimed with ease-in-out via ffmpeg.

5

Deck Stitcher

Assembles final_deck.pptx and deck_live.html. All five agents share slide_deck.json as a Pydantic v2 contract each stage enriches.

How It Works · The Craft

The craft is in the details that hide the seams.

Small disciplines are the difference between “cinematic” and “obviously AI-generated.”

Strict 16:9 Throughout

Any drift and transitions show an edge jump. GPT Image renders 2560×1440; Pillow crops to 1536×864 for Veo. Zero tolerance for aspect-ratio drift.

Veo Prompt Discipline

presentation, slide, deck, PowerPoint, chart and kin are banned from Veo prompts — they make Veo hallucinate slide content in intermediate frames.

Transition Easing

video_processor.py holds the first and last 0.4s at natural speed and compresses the middle — real Veo frames, no interpolation artifacts.

Even the file format fights back: pptx_fixer.py patches four python-pptx bugs, and a 10-slide deck ships as 19 PPTX slides (10 content + 9 video interstitials) because <p:transition> can't embed video.
