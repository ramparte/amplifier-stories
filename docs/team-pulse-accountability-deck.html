The problem

Status theater
kills teams

🎭

Performance, Not Progress

Standups become recitals. People report what they touched, not what moved. Nobody connects daily work to quarterly goals.

📋

Audit Amnesia

By Friday, nobody remembers what actually shipped. Managers reconstruct the week from chat threads and gut feel. Evidence evaporates.

🔍

Invisible Coordination

Cross-team connections happen by accident. Two people solve the same problem in parallel. Leverage points go unnoticed until it's too late.

Every team has outcomes on a slide somewhere. The question is whether anyone can trace this week's work back to them — with evidence, not narrative.

The anchor

Everything hangs off
one quarterly outcome

Team Pulse starts from observable, time-bounded outcomes with short IDs — then automates a four-step loop that keeps every week tied back to them.

1

Set Outcomes

Each team member defines quarterly outcomes with short IDs. The anchor for everything that follows.

2

Log Commitments

Weekly commitment logging ties this week's work to those outcomes — collection, file writing, cascade, and git commit, all automated.

3

Pull Activity

Daily GitHub pull fetches real commits, PRs, and reviews into per-person activity files. Evidence, not self-reporting.

4

Audit & Showcase

End-of-week: outcome-first audits, cross-team coordination analysis, and narrative showcases — all from real data.

How it stays honest

You can't game what you didn't do

The single claim of this beat: the record is built from evidence the system pulls itself, not from what anyone says they did.

Activity, pulled automatically

Commits, PRs, and reviews stream in from GitHub daily; Teams standup transcripts arrive via Graph API and are processed into structured commitments. Four data sources feed one accountability loop — no human triggers.

Audited against commitments

Audits cross-reference what each person committed to against what actually landed, mapped back to outcome IDs. The gap between claim and evidence is the whole point — and it's visible.

The payoff

One command chains the entire week

The weekly-cycle recipe sequences three sub-recipes into a single end-of-week run — each writes files and commits to git; the orchestrator sequences and reports.

1

pull-activity

Fetches GitHub events, builds per-person activity files, runs the github-activity cascade, and commits everything in one shot.

2

prep-audit

Identifies the week's data, processes per-person audit and review files in parallel, then assembles team-level views.

3

generate-coordination

Reads every weekly review and audit view, then synthesizes cross-team connection signals, themes, and leverage points.

The result: what each person shipped, how it maps to outcomes, and where teams are unknowingly working on the same problems — the complete accountability picture, from one run.

Beyond one team

Coordination sees what no single team can

The one claim here: because every team's reviews land in the same place, the system can spot overlap and leverage that's invisible from inside any one team.

The generate-coordination recipe reads all weekly reviews across teams and synthesizes connection signals, shared themes, and leverage points — surfacing collaboration two teams would otherwise stumble into by accident, weeks late.

Two people solving the same problem in parallel stop being a Friday surprise and become a Monday signal.

The turn

Automated — but never unsupervised

The pivot: this isn't a SaaS black box. The record is a repo you can diff, and a human signs off before anything goes public.

Git as the system of record

Every recipe writes files and commits to git. Commitments, activity, audits, coordination views — all versioned, all auditable, all diffable. No SaaS database. Just a repo.

Human-in-the-loop showcases

draft-showcase is a staged recipe: the agent generates outcome-first narratives, but a manager reviews and approves before anything posts to Teams via webhooks. Automation with judgment.

Why it matters

Outcomes first, evidence always

Team Pulse replaces the performance of a status update with a trail you can trust: real activity, tied to real outcomes, reviewed by a real person, versioned in git. Accountability stops being a story someone tells on Friday — and becomes something the week itself proves.
