The Payoff

The safe path is
the only path

Type what you want in natural language. OpenM365 decomposes intent into an inspectable plan, enforces safety policy at every step, executes against Microsoft Graph — and keeps a rollback point the whole way.

Compliance is not advisory. It is structurally enforced by the execution kernel before any application code runs — so an agent literally cannot reach Graph except through the guard rails. Everything that follows is how that invariant is built.

The Request Pipeline

Intent becomes a safe, reversible plan

1

Intent

Natural language is classified and decomposed by the Intent Kernel into a structured, inspectable execution plan. No ambiguity reaches the API.

2

Plan

The Planner validates scope, estimates cost, resolves resource dependencies, and pre-checks RBAC permissions — before a single API call is made.

3

Execute

The Executor runs each step through the 8 constitutional safety hooks, then calls Microsoft Graph. Dry-run mode shows exactly what would happen first.

4

Checkpoint & Rollback

Every mutating operation creates a checkpoint. The user sees what changed, approves the batch, or rolls everything back to any prior state.

Constitutional Safety

“Safe” is 8 specific hooks, on every call

The executor invokes the full pipeline before every tool call — there is no fast path that bypasses any of them.

Who & What

  • Entra Identity — every op tied to a real Azure AD principal
  • RBAC — YAML role hierarchy, pre-flight permission checks
  • DLP — sensitive content detected before it leaves the boundary
  • Tool Gateway — sandboxed execution, tools can't exceed declared scope

How Much & Whether

  • Cost Control — per-op estimation, rejects over-budget plans
  • Approval Workflow — human-in-the-loop gate for destructive ops
  • Audit — full forensic log of identity, params, and outcome
  • Rate Limiting — per-user/tenant throttling protects Graph quotas
