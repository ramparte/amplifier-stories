Act III — The Blueprint

The orchestrator pattern: the main session delegates and never touches code directly. Worker agents implement, test, and report back — driven by a 528-line implementation prompt covering 19 features.

Act III — Safeguards

The prompt even carried survival protocols to keep it alive

Built into the 528-line prompt — instructions for staying alive across context windows.

📄
Create SESSION-HANDOFF.md External memory file — the AI's lifeline across context compactions
🔄
Update it after each feature, and read it on compaction to resume Track what's done and what state the code is in — never start from scratch, always pick up where you left off
⚠️
Don't stop until the 10-Act test passes The acceptance test is both the goal and the finish line

Remember these protocols. In the next four hours, every one of them is forgotten.

Act V — The Crash

Then it tried to watch itself work — and fell 35 levels deep

The Recursion Loop

The AI reached for browser-operator to visually verify its own work — and got stuck in a 35+ nested recursion loop: spawning sub-agents to look at the browser, which spawned sub-agents to look at the browser, which spawned…

depth: 35+ and counting...

The Forgotten Protocol

SESSION-HANDOFF.md was never updated. The survival protocol — the AI's external memory across compactions — was the first thing it forgot.

The Blind Builder

1,538 lines that compile — but nobody, human or AI, had verified they actually work. That is why the scorecard reads 0/19.

What the Crash Taught Us

Autonomous builds need a verification loop — the build is only half the job

👁
Building blind produces output of unknown quality The build step is only half the job; without a verification loop, "done" means nothing.
🧠
External memory only works if you use it SESSION-HANDOFF.md was the survival protocol. The AI forgot it first. Memory requires discipline.
🎬
The 10-Act test is a powerful spec technique Specification and verification in one artifact — a user story that doubles as acceptance criteria.

This crash directly inspired amplifier-bundle-ui-vision — AI building visual-testing tools for itself, born from the necessity of never building blind again.
