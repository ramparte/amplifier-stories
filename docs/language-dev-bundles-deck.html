The Problem

Agents navigated code — then wrote it blind

LSP-only bundles let agents find definitions and references, but nothing verified their edits compiled or passed lint. And language support was scattered: multiple repos, no quality tooling, no composability. Every language was a silo.

LSP-Only Navigation
Agents could find definitions and references — but couldn't verify their edits compiled or passed lint. Write code, hope for the best.
No Quality Feedback Loop
No formatting checks. No type verification. No stub detection. Agents worked blind — errors surfaced only when humans reviewed.
No Composability
Want LSP without quality checks? Too bad. Want quality without LSP overhead? Can't. One bundle, one mode, take it or leave it.

lsp-rust

The Solution

Every bundle pairs navigation with a quality loop

The single move that fixes the blind-writing problem: bundle semantic navigation and quality tooling together, so agents write code, verify it compiles, check formatting, and catch lint issues without leaving the loop.

Navigate with LSP
→
Write / edit code
→
Quality checks run
→
Fix before human sees it
Navigation alone told agents where the code was. Pairing it with quality tooling tells them whether what they just wrote is correct — the difference between reading a map and getting feedback on the drive.
The Auto-Check Hook

Quality checks fire on every edit

This is the payoff. Every time an agent writes or edits a file, the hook automatically runs quality checks and reports results inline. No extra step. No forgetting to check. The write-then-hope loop is closed.

Foundation

One shared LSP base powers all three

Every language bundle builds on the shared LSP base (amplifier-bundle-lsp). 14 operations, custom routing, persistent warm servers, and zero external Python dependencies.

14
LSP Operations
goToDefinition, findReferences, hover, diagnostics, rename, prepareCallHierarchy, incomingCalls, outgoingCalls, and 6 more.
Custom
customRequest Routing
Unlocks server-specific extensions: rust-analyzer's expandMacro, relatedTests, externalDocs.
3×
Persistent Servers
Pyright, rust-analyzer, and typescript-language-server stay warm with idle timeout. No cold-start thrashing across delegations.
Zero external dependencies
The tool-lsp module has zero external Python dependencies. 421 test functions across 18 test files. 1 behavior, 1 module, 1 agent (code-navigator).
Backward Compatible

Old bundles still work — zero-breakage migration

Adoption is safe: the old LSP-only bundles are now thin forwarding stubs that show a deprecation warning with migration instructions. No breakage — just a nudge.

Before DEPRECATED
# Old LSP-only bundles
amplifier bundle use amplifier-bundle-lsp-python
amplifier bundle use amplifier-bundle-lsp-rust
amplifier bundle use amplifier-bundle-lsp-typescript

# → Shows deprecation warning
⚠ lsp-python is deprecated.
  Use python-dev for LSP + quality.
After NEW
# New comprehensive dev bundles
amplifier bundle use amplifier-bundle-python-dev
amplifier bundle use amplifier-bundle-rust-dev
amplifier bundle use amplifier-bundle-typescript-dev

# → Full dev experience
✓ LSP + quality + agents ready
hooks-deprecation module
