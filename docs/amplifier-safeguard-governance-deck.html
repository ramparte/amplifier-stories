The Complication

Today CIOs can’t see it, govern it, or audit it

🕶️

Shadow AI

Thousands of employees using Copilot, ChatGPT, Claude, Cursor, and custom agents. No one knows what data is leaving the building.

🛡️

No Control Surface

Agents read documents, write code, access internal systems, and make decisions — with zero policy enforcement at the organizational level.

📊

Audit Black Hole

When compliance asks “what AI is doing in Legal?” the answer today is “we don’t know.” Every agent interaction is unlogged and invisible.

This is the “shadow IT” problem of the AI era — but with higher stakes. Agents don’t just access data, they act on it.

— Product Vision, amplifier-safeguard
The Resolution

Every agent must call an LLM to think — so there’s one choke point

Palo Alto Networks’ founding insight: all network traffic flows through the network, so a firewall that sits inline sees everything. The agent equivalent — all agent work flows through LLM API calls. Sit inline there and nothing an agent does is invisible.

From that single API call the gateway determines WHO is using WHAT KIND OF AGENT with WHAT CAPABILITIES to do WHAT KIND OF WORK with WHAT DATA — and can allow or deny it. No endpoint agent. No framework integration. No cooperation from the AI vendor.

— Architecture Design Doc, 02-ARCHITECTURE.md
The Telescope · Claim 1

A single API call reveals who, what agent, and what data

Every agent — Copilot, ChatGPT, Cursor, Amplifier, custom — sends the gateway the same rich payload. Three reads turn it into organizational intelligence.

Who

The gateway API key maps to a real identity — user, department, role, groups — via Entra ID, in sub-5ms from an in-memory cache.

What Agent

The system prompt reveals what the agent IS; the tool definitions reveal what it CAN DO. Capability, not guesswork.

What Data

The conversation history reveals what the agent HAS BEEN DOING — and exactly which data it touched.

The Control Surface · Claim 2

Two policy paths turn the telescope into an enforcement point

Fast Path (Inline)

  • Provider allow/deny by department and role
  • Model restrictions per user group
  • Rate limits per user and department
  • Regex content patterns (SSN, credit cards, secrets)
  • Tool restrictions (no bash for non-engineering)

<10ms · Deterministic · No LLM · can block

Slow Path (Async)

  • Contextual PII detection beyond regex
  • Sensitive data classification (contracts, financials, code)
  • Intent classification — what is the agent trying to do?
  • Prompt injection detection
  • Review queue for the security team

Never blocks inline · Retrospective · LLM-powered

Policies are written in natural language: “Legal can only use Azure OpenAI” compiles into a structured rule, previews its impact against historical data, then deploys with an optional grace period.

Complete Coverage · Claim 3

Three planes make the choke point inescapable

🛡️

Gateway (Data Plane)

Handles sanctioned traffic — full inspection, policy enforcement, structured logging of every request/response pair.

🌐

DNS Backstop

Catches shadow AI — personal keys and consumer tools pointed straight at providers — using existing network infra.

💬

Management Plane

An Amplifier-powered NL interface: the CIO talks to an agent, not a dashboard, to create policy and read analytics.

Sanctioned calls flow through the gateway; unsanctioned ones are blocked at DNS and forced back through it. There is no path around the choke point.

Why It Matters

Ten distinct agent threats collapse into that one choke point

The agent is both the attack surface and the worker. Because every one of these threats must pass through an LLM API call, the gateway is where they’re caught.

Data Exfiltration

Secrets, PII, and trade secrets leaking through prompts to external providers — caught by content inspection.

Tool Abuse & Destructive Actions

A summarizer that starts running shell commands; rm -rf or DROP TABLE from injection — caught by tool restrictions.

Compliance Violations

Unlogged access to regulated data — GDPR, HIPAA, SOX — caught by logging every call.

Prompt injection, privilege escalation, supply-chain, and agent-to-agent poisoning round out the ten — all detected at the same LLM API bottleneck.
