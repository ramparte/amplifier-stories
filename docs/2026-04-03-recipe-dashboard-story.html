The Problem

Recipes run for minutes to hours — and you have no idea what’s happening

So you switch back to the terminal, scroll through logs, or just keep asking “where is it at?” Four questions you can never answer at a glance:

🤷 Is it still running?
📍 Which step is it on?
🛑 Did it stall?
✋ Is it waiting for me?
The Payoff

One command. Opens a browser. That’s the whole install.

uvx --from git+https://github.com/samueljklee/amplifier-recipe-dashboard \ amplifier-recipe-dashboard
✓ No API keys
✓ No LLM calls
✓ Just reads your local ~/.amplifier/ session files

Nothing leaves your machine. The rest of this deck shows what that browser tab gives you.
