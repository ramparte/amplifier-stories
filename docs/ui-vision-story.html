Hands-Off Dev Time

The build was flawless. The problem came when it tried to look at what it made.

What it was building

The target was the Canvas Artifact Viewer — specified down to 1,021 meticulous lines

The Canvas team wrote a full UX spec for an in-app file browser for AI-generated code, then handed it to Amplifier to build. Remember this artifact — it's what the agent will fail to see.

CANVAS-ARTIFACT-VIEWER-SPEC.md
25 Kepler desktop screenshots analyzed. 17 interactive HTML mockups prototyped. 21 sections covering every detail from file-tree styling to VS Code-inspired badges, plus a 10-Act acceptance test scripting the exact verification sequence.
The crash

Asked "does this look right?", the session spawned 35+ nested agents and died

To visually verify the Artifact Viewer, the session delegated to a browser-operator. It couldn't process what it saw, so it spawned another. Then another.

// What the session tried to do: delegate browser-operator "Check if the UI looks right" -> delegate browser-operator "Navigate and verify" -> delegate browser-operator "Take screenshot" -> delegate browser-operator "Analyze screenshot" -> delegate browser-operator "..." // 35+ levels deep - context window exhausted - session crashed

It died before updating SESSION-HANDOFF.md — every feature left PENDING, every acceptance test NOT TESTED. The build was blind.

The reframe

The crash wasn't a failure.
It was a requirements doc.

AI agents need eyes, not just code. Building UI without visual verification is building blind — and now the fix was obvious.

The payoff

Overnight, the AI built its own eyes — and by 11:25 the next morning it saw its UI

How it sees

Each answers a single, bounded question about your UI — no open-ended "is this right?" that spirals.

Composability

A 31-line behavior YAML drops those eyes into any Amplifier bundle

The entire capability composes in like a LEGO brick — two lines to add visual testing to an existing bundle.

# Compose vision into an existing bundle includes: - bundle: git+...ui-vision@main #subdirectory=behaviors/ui-vision.yaml
