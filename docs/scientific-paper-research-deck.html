The Problem

AI helps you
write — not think

🧪

Rigor Takes a Decade

Precise questions, locked methodology, honest reporting against yourself, proper citations — researchers learn these over years. Everyone else reinvents the mistakes.

🚨

Overclaiming Everywhere

LLMs default to confident prose. Without guardrails, exploratory findings get reported as confirmatory — and causal language replaces correlation.

📚

Format Fragmentation

NeurIPS, ACL, IEEE, USPTO, NSF — every venue has different templates, page limits, and compliance checklists. Each one is a manual burden.

Scientific rigor is a set of habits. The question is whether a machine can enforce them — so a patent attorney, a policy analyst, or a first-time author all get the same scaffolding and the same honest critic.

The Pipeline

Six disciplined modes,
question to publish

The bundle walks you from raw intuition to venue-ready output — with the lockdown and pivot enforcement built into the path, not bolted on after.

1

/question

Sharpen a rough claim into a falsifiable question with explicit predictions, named mechanisms, and disconfirmation criteria.

2

/study-plan

Lock methodology before seeing results. Hash-sealed pre-registration with power analysis, named tests, and alpha levels.

3

/execute

Run the analysis, gather prior art, or pull evidence — depending on what you're making. An execution log tracks every step.

4

/critique → /draft → /publish

Honest peer review names specific limitations. Draft produces venue-structured output. Publish is where discipline gets teeth —

The Payoff

/publish blocks until you admit
where the data proved you wrong

This is the move a decade of training teaches and confident AI never will: when results contradict the pre-registered plan, the finding is automatically relabeled exploratory, and publishing halts until you acknowledge the pivot.

Honest-Pivot Enforcement

Data that contradicts the pre-registration can't quietly become a fresh hypothesis. Exploratory findings are labeled as such — no silent overclaiming, no rewriting history.

The Honest Critic Has a Veto

It issues BLOCK / WARN / NOTE findings and argues against your work — overclaiming, methodology gaps, alternative explanations. BLOCK items must be resolved before /draft.

Freeze the Method

A hash-sealed plan, locked
before you see a single result

Pre-registration lockdown is what makes honest-pivot possible: you can't rationalize a method to fit an outcome you haven't seen yet.

The preregistration-reviewer checks that predictions are specific and directional, tests are named, alpha levels are set, and minimum detectable effects are calculated — issuing pass / fail / warn per section before the plan is hash-sealed.

No Grading Your Own Homework

Critique is routed through a
different vendor than the one that drafted

A model asked to review its own output tends to approve it. The cross-vendor judge mitigates that reflexivity hazard by design.

The drafting model and the critiquing model come from different LLM vendors — so the honest critic's BLOCK/WARN/NOTE findings come from a genuinely independent reader, not a rubber stamp.

Rigor Reaches the Figures

PaperBanana vetoes a figure
against 8 quality rules

The same discipline applied to claims is applied to visuals — multi-agent figure generation that won't ship a misleading chart.

Vector format · readable text (≥8pt) · colorblind-safe palette · error bars · white background · proper aspect ratio · no misleading axis truncation · unobstructed legends. Fail any veto rule and the figure doesn't pass.
