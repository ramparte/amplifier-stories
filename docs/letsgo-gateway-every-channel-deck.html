Channel Adapters

18 platforms through one pluggable adapter system

The breadth isn't 18 integrations hard-coded into the gateway — it's one adapter contract that any platform can satisfy.

5 Built-In

Webhook, WhatsApp, Telegram, Discord, and Slack ship with the gateway daemon — ready the moment you install.

13 Plugins

Signal, Matrix, Teams, iMessage, LINE, Nostr, IRC and more install as plugins via letsgo.channels entry-point discovery — no gateway code changes.

Each adapter normalizes its platform's inbound messages into one common format. Add a new channel by registering an entry point — the gateway never has to know about it in advance.

Security

It only reaches people who reached it first

"The AI should only be able to reach someone who has first reached out to the AI and been approved."

— The Meta-Rule, enforced at the daemon level for all channels, all send paths
1

Daemon Layer

Blocked sender/recipient patterns silently dropped before auth — broadcast addresses, newsletters, system accounts filtered across all channels.

2

Channel Adapter Layer

Per-channel filtering: Telegram DM-only, Discord DM-only, system events dropped. Each adapter enforces its own safety defaults.

3

Outbound Layer

Hard block on any outbound to unapproved recipients. 6-character single-use pairing codes with admin approval. Dry-run mode for testing.

Beyond Chat

Not just messaging — a full agent platform

The same agent can remember, run untrusted code safely, and talk back in your voice — all from any channel.

🧠

Bio-Inspired Memory

8-module pipeline: capture, score memorability, consolidate, compress, inject. SQLite + FTS5 with BM25 ranking, temporal decay, and cross-session continuity.

📦

Docker Sandbox

Isolated execution for untrusted code. 512MB memory, 1 CPU, 120s timeout, no network. Run anything safely from any channel.

🎙️

Voice Pipeline

Whisper transcription + TTS via ElevenLabs, edge-tts, or OpenAI. Send a voice note on Telegram, get a text reply — or vice versa.

Plus: encrypted Fernet secrets store, Canvas visual workspace, and MCP tool-server bridging — extend capabilities without touching gateway code.
