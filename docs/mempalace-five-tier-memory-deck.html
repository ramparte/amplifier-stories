Why It Matters

Without memory, every session is the agent’s first day

🧠

Context Window Limits

Every session starts from zero. Agents can't recall what you discussed yesterday, last week, or last month.

🔄

Repeated Explanations

You re-explain your preferences, project decisions, and architectural choices in every single conversation.

🔍

Lost Discoveries

Gotchas, debugging insights, and hard-won knowledge vanish when the session ends. Future sessions repeat past mistakes.

A brilliant colleague with permanent anterograde amnesia — every conversation is their first day on the job. That is what a 96.6% recall score is actually curing.

The Payoff

Memory that speaks up — but only when it’s worth saying

The interject hook is the felt payoff: mid-session, it surfaces the one relevant memory you'd forgotten — and stays silent otherwise.

Non-Disruptive by Design

Fires on prompt_submit, tool_pre, and orchestrator_complete events, but only surfaces a memory once cosine similarity clears 0.72. In the uncertain band, an LLM judge decides relevance.

Fully Observable

Every hook emits structured events to ~/.mempalace/events/{session_id}.jsonl. Watch it live with palace events or tail -f. Per-hook kill switch: emit_events: false.

The worst memory system is the one that interrupts you with irrelevant trivia. MemPalace's interject hook says nothing unless it has something genuinely worth saying.

Mechanism — The Five Tiers

Five tiers, each tuned to a different kind of recall

High recall isn't one clever index — it's routing each query to the store that answers it best.

🔮

Semantic Vectors

Verbatim storage with embedding-based similarity search — the 96.6% R@5 engine.

🕸️

Knowledge Graph

Subject-predicate-object triples. Cross-wing traversal and relationship queries.

📋

Coordination Files

HANDOFF.md, GLOSSARY.md, PROJECT_CONTEXT.md — markdown that survives git clones.

🗄️

SQLite Fact Store

FTS5 full-text search for explicit key-value memories. Fast structured lookups.

📓

Agent Diaries

Per-agent session journals: what was worked on, learned, and what comes next.

The palace metaphor — wings, rooms, drawers — gives agents one intuitive spatial model to navigate all five tiers at once.

Mechanism — The Session Loop

Memory captures and curates itself — no “remember this” required

1

Session Briefing

hooks-mempalace-briefing assembles a wake-up briefing from semantic search, knowledge graph, agent diary, and HANDOFF.md. Importance re-ranking surfaces what matters most.

2

Auto-Capture

hooks-mempalace-capture files verbatim tool outputs as palace drawers with auto-detected wing and room. Nothing to tag by hand.

3

Mid-Session Interject

hooks-mempalace-interject surfaces relevant memories at the right moment — the payoff hook, firing only above 0.72 similarity.

4

End-of-Session Curation

The Curator runs three phases: palace curation, coordination-file updates (HANDOFF.md, PROVENANCE.md), and KG enrichment with importance scoring and duplicate linking.

Mechanism — The Agents

Three agents split the read and write paths cleanly

🔍

Archivist

The read path. Precise palace search, KG queries, graph traversal, and coordination-file reads. Invoked on-demand when you need to find something.

🗣️

Docent

Conversational memory Q&A. Ask in plain language: “What decisions have I made about auth?” or “Summarize last week's work.”

✍️

Curator

The write path. Palace curation, KG enrichment with importance scoring, HANDOFF.md updates, and duplicate linking. Runs at session end and on-demand.

Coordination files (PROJECT_CONTEXT.md, GLOSSARY.md, HANDOFF.md) are readable by Amplifier, OpenAI Codex, GitHub Copilot, Cursor, and Windsurf — memory that travels with the repo.

Trust

Built to be trusted: nothing deleted, nothing leaves your machine

A memory you'd actually run in production has to be safe by default — not just accurate.

Local-First

All data stays on your machine at ~/.mempalace/. Nothing leaves your environment.

Zero Deletion

Duplicates are preserved with low importance, never dropped. KG enrichment and garden analysis are purely additive.

Graceful Degradation

Without the engine installed, the bundle runs in coordination-files-only mode. Palace features silently skip.

Backed by a near 1:1.2 test ratio — 4,313 lines of source against 5,347 lines of tests — exercising the full briefing → capture → interject → curation lifecycle.

The Bigger Picture

Five separate memory modules, consolidated into one persistence layer

MemPalace is the layer that makes agent continuity possible — memory as infrastructure, not a bolt-on.

One Bundle, Not Five

Supersedes amplifier-bundle-memory, amplifier-bundle-project-memory, amplifier-module-context-memory, amplifier-module-tool-memory, and amplifier-module-hooks-memory-capture into one cohesive system.

Research-Backed

Wings are projects, rooms are topics, drawers are memories — the same spatial mnemonic humans have used since ancient Greece, handed to an agent.
