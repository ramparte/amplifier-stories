The Garden · An Experiment in the Human–AI Interface

When the AI writes the code,
what’s left for you to do?

That question is the whole point of this piece. If a machine can turn a description into working software, the real craft moves to the interface — how a human asks for what they want, watches it happen, and stays in control. The Garden is a working experiment in exactly that: you plant a seed, and a reviewed pull request grows.

Why it matters: this is a preview of what “building software” starts to feel like when writing code stops being the job. First, the proof that it actually runs.

The real problem

The code is the easy part now

The AI can already write the code. The unsolved problem is designing the experience around it — how humans express intent, observe progress, and stay in control without micromanaging.

The hard question isn't "can AI write code." It's "what's the right way for a human to talk to the system that writes code."

How it works

One pipeline: from a
sentence to a pull request

The single claim: every step between intent and PR is automated — a small cast of services hands the work down the line.

01 Create a project → Gitea repo + webhook auto
02 Describe what you want as an issue → issues-to-brief turns it into a spec LLM
03 amplifier-resolve spawns a container → generate tests → write code → converge AI agent
04 PR created → you review → you merge human

Why it matters

Designing the experience
is the real work now

The factory metaphor dominated our industry for decades and made everything worse. When the machine writes the code, the craft that's left is the interface — how a person expresses intent, sees progress, and stays in control.

The Garden is one exploration of that craft — a small cast of services (Gitea, issues-to-brief, amplifier-resolve, CXDB) wired so a sentence becomes a harvest.
