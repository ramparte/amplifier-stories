The Complication

Terminal sessions
live on islands

You shouldn't have to remember which machine is running what.

🖥️

SSH Whack-a-Mole

Sessions run on your dev box, your build server, and a VM. Checking them means SSH’ing into each machine one at a time.

🚫

No Mobile Access

Terminal apps on iOS are clunky. There’s no good way to glance at running sessions from your phone or tablet.

🔔

Missed Activity

A build finishes, a test fails, a process bells — but you don’t notice until you reconnect and check.

Your sessions should come to you.

The Payoff · Federation v0.3.0

One dashboard,
every machine

Multiple muxplex instances federate into a unified view. Sessions from all your devices appear together, each tagged with a device badge — and bells clear across servers so no notification goes stale.

Run one instance per machine, point them at each other once, and every session — local or remote — lives in the same tab. That unified, self-syncing view is what the rest of this deck is built to earn.

How Federation Works

Independent instances, one self-syncing view

Each machine runs its own muxplex; they poll, merge, and reconcile each other with no central server.

1

Remote Aggregation

Configure remote instance URLs in Settings. The poll cycle fetches sessions from each remote, merging them into the local dashboard with device badges.

2

Settings Sync

Preferences sync across all connected servers via a P2P newer-wins protocol with per-server timestamps. 30-second poll. Offline servers catch up automatically on reconnect.

3

Heartbeat Bell Clearing

Viewing a remote session clears its activity bell on the remote server via POST /api/bell/clear. No stale notification badges across federation.

4

Secure & Resilient

Bearer token auth between instances, self-signed TLS accepted, and unique remoteId:name keys prevent collisions for identically-named sessions on different machines.

The Dashboard

See every session — and never miss activity

Live snapshots and activity signals mean you monitor a whole fleet without reconnecting to anything.

Live Session Grid

ANSI-colored snapshots as preview tiles. Auto (scrollable) and Fit (fill viewport) modes, with configurable columns and font size.

Activity Indicators

Bell badges glow on tiles with unseen activity. The tab shows a (N) count and the favicon gets an amber dot — so you notice from another tab.

Hover & Manage

Hover a tile for a full-size preview; the sidebar quick-switches sessions. + creates sessions on any federated device, × deletes.

Terminal & Mobile

A full terminal — even on your phone

The island problem dies on mobile too: real terminals, real clipboard, in Safari.

📋

Native Clipboard

Ctrl+Shift+C to copy, mouse-select auto-copies. An OSC 52 bridge sends tmux copy-mode selections to the system clipboard.

🔍

Search, Links & Images

Ctrl+F scrollback search, Ctrl+Click to open URLs, and inline Sixel/iTerm2 images — file managers like yazi render previews in the browser.

📱

iOS / iPadOS

Touch-scroll fixes for Safari and a PWA manifest — add to home screen for an app-like experience. Responsive from phone to desktop.

Not A Toy

Engineered to trust on your real fleet

A tool you leave running on every machine has to be solid — so it's built on a clean stack and out-tested 2-to-1.

Clean Stack

  • Python 3.11+ FastAPI backend, xterm.js + ttyd terminals
  • WebSocket proxy for federation terminal access
  • httpx async federation; Hatchling build via uv/pip
  • systemd (Linux/WSL) and launchd (macOS) services
  • PAM or password auth, signed session cookies, auto-TLS

2.2:1 Test Ratio

22,679 lines of tests (Python + JS) against ~10,000 lines of source across 18 test files — covering API, CLI, frontend rendering, CSS validation, and federation sync.

muxplex doctor diagnoses, muxplex upgrade self-updates and restarts the service. Config lives in ~/.config/muxplex/settings.json.
