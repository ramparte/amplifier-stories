Self-Validation, Green

Reality-Check now tests a copy of itself.

Reality-Check is Amplifier's testing bundle; a Digital Twin Universe (DTU) is the disposable Linux sandbox it runs inside. Today the loop runs green end to end — Reality-Check validating a copy of Reality-Check, one DTU nested inside another.

profile → run → evidence → summary: the whole self-validation loop completed against the testing tool itself.

Author David Koleczek
The Irony

The tool built for testing couldn't test itself.

As I built out the Digital Twin Universe bundles, I hit the irony head-on: I literally couldn't use the thing for the one job it exists to do — testing. A container can't cleanly launch the containers it needs to test. Container-in-container is the wall.

Nesting

A DTU can host its own DTU.

The unlock is a single move: let the outer DTU stand up an inner one. Now the testing infrastructure can test itself — and anything else riding on it — because the sandbox it needs lives one level down, cleanly isolated from the sandbox it runs in.

The Loop

Profile → run → evidence → summary — aim it at anything.

With nesting in place, self-validation becomes a repeatable four-step loop. Point it at Reality-Check to test Reality-Check today; point it at any app tomorrow.

Earning Its Keep

Nesting caught a real hang the moment it existed.

Root cause: subprocess.run with capture_output=True was waiting for grandchildren (like lxc monitor spawned by a nested incus launch) to close inherited file descriptors — even after incus exec itself had exited. Self-testing surfaced the bug immediately.

The Fix

Hand subprocess tempfiles, not pipes.

# incus.py :: exec_command() - result = subprocess.run(cmd, capture_output=True, text=True, timeout=timeout) - return result.returncode, result.stdout, result.stderr + with tempfile.TemporaryFile("w+") as out_f, tempfile.TemporaryFile("w+") as err_f: + result = subprocess.run( + cmd, + stdin=subprocess.DEVNULL, + stdout=out_f, + stderr=err_f, + text=True, + timeout=timeout, + ) + out_f.seek(0); err_f.seek(0) + return result.returncode, out_f.read(), err_f.read()

subprocess.run now returns as soon as incus exec exits, regardless of what grandchildren are still holding inherited fds. stdin=DEVNULL keeps the child from blocking on inherited input.

Run & Report

Run inside, pull the evidence, let Amplifier summarize.

Drive reality-check against the inner app, tee the output to a log, then pull the artifacts back out and let Amplifier read them.

# inside the outer DTU amplifier run "Run the reality-check-pipeline recipe against the app at /software" | tee $OUT/run.log # then pulled back out of the DTU /root/home -> $OUT/home/ /root/.amplifier/projects -> $OUT/sessions/

Amplifier then generates a summary of what happened based on the logs.
