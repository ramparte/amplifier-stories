The Beginning
It started with Python — and one superpower: agents that understand code
Amplifier launched Python-only. The Language Server Protocol (LSP) let agents understand code instead of grepping text — exact definitions, real callers, inferred types.
Before: Text Search
# grep "authenticate" across 500 files # matches comments, strings, variable names # no type info, no call chains $ grep -r "authenticate" src/ auth.py: # authenticate the user test.py: name = "authenticate_test" docs.md: Call authenticate() to...
After: Semantic Understanding
# LSP goToDefinition → exact source # findReferences → actual callers only # hover → full type signature → def authenticate(user: User) -> Token Called by: login(), refresh(), oauth() Returns: Token (inferred from impl) Defined: src/auth/core.py:42
The Problem
Hardcode every language and
you drown in M × N.
M languages × N tools = M×N custom integrations — the combinatorial trap LSP was invented to escape. LSP collapses it to M + N: one server per language, one client per tool.
M × N
Traditional: a custom integration
for every language × every tool
M + N
LSP: one server per language,
one client per tool. Done.
The Bet
The core carries zero hardcoded language knowledge
The tool-lsp module knows nothing about any language. Each language bundle injects its config via a YAML deep merge — so the engine is written once and never edited again.
lsp-python
languages.python: { ... }
lsp-rust
languages.rust: { ... }
lsp-typescript

The Payoff
Adding a whole language is just adding YAML
# rust-lsp.yaml — the entire Rust integration tools: - module: tool-lsp config: languages: rust: extensions: [.rs] workspace_markers: [Cargo.toml, Cargo.lock] server: command: [rust-analyzer] capabilities: diagnostics: true rename: true codeAction: true customRequest: true
No code changes. No new modules. The YAML deep-merges into tool-lsp's config; the module spawns rust-analyzer and exposes all 17 operations. That is the zero.
The Contract
Every language ships the same three files — and gets all 17 operations
Component Python Rust TypeScript
Behavior YAML python-lsp.yaml rust-lsp.yaml typescript-lsp.yaml
Agent python-code-intel.md rust-code-intel.md typescript-code-intel.md
Context python-lsp.md rust-lsp.md typescript-lsp.md
Language Server pyright-langserver rust-analyzer typescript-language-server
Author Microsoft Microsoft Community (robotdad)
Behavior YAML injects config, the agent supplies language-specific strategy, the context file guides usage. Navigation ops are always on; diagnostics, rename, inlayHints, and a customRequest escape hatch layer on per capability. That's the whole contract.
