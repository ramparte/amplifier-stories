What Superpowers Is

obra’s methodology, made Amplifier-native.

Superpowers is a bundle that takes Jesse Vincent’s obra/superpowers methodology — anti-rationalization, TDD, debugging, brainstorming — and wraps it in the layers Amplifier actually runs: skills, modes, agents, and recipes.

v2 touched every layer at once. But the change that matters most is not any single layer — it’s where the methodology now comes from.

The Old Way

Copied skills drifted, and enforcement was duplicated everywhere.

7 bundle-owned skill copies
  • Methodology copied into our bundle repo
  • Drift from upstream as obra kept iterating
  • Manual sync needed for every update
  • Unclear which version we were running
Anti-rationalization, duplicated
  • Spirit-vs-letter / YAGNI text pasted into every mode
  • Updating meant editing each mode individually
  • Drift between modes was inevitable
  • Enforcement quietly diverged over time

Two kinds of duplication, one root cause: the bundle owned content it should only have been referencing.

The Reframe

One ownership line makes every upstream improvement arrive automatically.

As Jesse iterates on anti-rationalization, TDD, debugging, and the rest, those improvements now flow to us with no manual sync. We maintain just 2 Amplifier-specific skills — listed first, so we can override when we need platform-specific behavior.

The right architecture
We own the platform integration and enforcement mechanisms; Jesse owns the methodology content. Our bundle references his skills at runtime and overrides only where Amplifier needs something specific. Clear boundary, automatic updates.
Consistent Enforcement

Anti-rationalization now lives in one file, @-mentioned by every mode.

Cross-mode enforcement — spirit-vs-letter, YAGNI, false-completion detection, scope-creep prevention — moved into a single shared context file. A new ecosystem capability lets mode bodies resolve @-mentions, so that one file is always in attention when a mode is active.

Before
  • Enforcement text duplicated across modes
  • Every update meant editing each mode
After
  • One shared file, @-mentioned from every mode body
  • One place to update — consistent enforcement everywhere
Modes

All six modes carry the latest enforcement and completion discipline.

Every mode was enriched with current thinking on escalation signals and knowing when work is actually done. Three that show the flavor:

🐛
Debug
“3+ fixes → question the architecture” escalation, plus human-partner signal recognition.
⚡
Execute-plan
A structured status protocol: DONE / DONE_WITH_CONCERNS / NEEDS_CONTEXT / BLOCKED — no free-form guesswork.
📝
Write-plan
Plan-size guidance: more than 15 tasks → split into phases. Brainstorm, Verify, and tool-based mode activation rounded out the six.
Agents

Three agents gained status protocols, architectural review, and built-in distrust.

The agents that carry the work now report and review more rigorously.

🔨
Implementer
Structured exit codes (DONE, DONE_WITH_CONCERNS, NEEDS_CONTEXT, BLOCKED) instead of free-form text, plus guidance on when to escalate vs. proceed.
🔍
Code Quality Reviewer
Architecture-level checks, not just line-by-line, with YAGNI enforced at the review layer.
🛡
Spec Reviewer
Strengthened institutional distrust: “the implementer finished suspiciously quickly” is now built-in skepticism.
Recipes

Recipes got retries, real sub-recipe composition, and tuned timeouts.

Reliability fixes across the pipeline — including an ecosystem capability, staged sub-recipe composition with approval gates, that every bundle now gets.

🔁
Retry with backoff
Exponential backoff on all agent steps — API hiccups no longer kill pipeline runs.
🧩
Sub-recipe composition
The full-development-cycle recipe now properly composes the SDD recipe via staged sub-recipes — fixing a gap where it used self-review instead of the three-agent pipeline.
⏱️
Timeout tuning
Plan-writer and load-plan timeouts bumped for large plans — no more premature timeouts on complex projects.
Get Started

Update, restart, and you’re on v2.

Update Amplifier to get the latest bundles, then start or restart your session — the improvements are active immediately, and the platform gains (@-mentions in modes, staged sub-recipes, bundle source overrides) ship for everyone.
